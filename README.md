
# Data Cleaning & Structural Validation

## Project Overview
This project focuses on cleaning and organizing raw data using Microsoft Excel to improve data quality, consistency, and reliability.

## Objective
To transform raw and unstructured data into a clean, consistent, and reliable format while maintaining data integrity.

## Tools Used
- Microsoft Excel

## Data Cleaning Process
- Identifying and removing duplicate records
- Handling missing values
- Correcting inconsistent text formats
- Standardizing date and number formats
- Adjusting column widths and alignment
- Organizing data into a structured format

## Outcome
The dataset was cleaned and formatted to improve readability, consistency, and overall data quality.

## Project File
- `Data_Cleaning_Final.xlsx` – Cleaned Excel dataset.

## Conclusion
This task provided practical experience in data cleaning, spreadsheet formatting, and structural validation using Microsoft Excel.
